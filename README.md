# Portfólio — Janaína Duarte

Site estático para GitHub Pages com foco em **dados** e **tecnologia**.

## Preview local

Abra `index.html` no navegador ou use um servidor local:

```bash
cd site
python -m http.server 8080
```

Acesse: http://localhost:8080

## Publicação no GitHub Pages

Este repositório está **privado** para revisão. Quando aprovar:

1. Atualize o e-mail em `index.html` (seção contato)
2. Faça merge/push para `Duartejanaina/duartejanaina.github.io`
3. Em **Settings → Pages**, confirme deploy da branch `main`

URL final: https://duartejanaina.github.io
